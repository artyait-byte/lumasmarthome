# Brand marks

Each file is the maker's own logo, rendered in one dark ink by CSS
(`.fx-brand img` in css/spa.css), so colour in the source does not matter.

| file | source |
|---|---|
| lutron.svg | lutron.com site header (`/us/themes/custom/lutron/logo-black.svg`) |
| savant.svg | savant.com site header |
| sonance.svg | sonance.com site header (inline SVG) |
| clare.svg, wattbox.svg | snapone.com brand sheet (Snap One owns both) |
| rti.png | RTI brand page on avproglobal.com (RTI's owner); only a PNG is published |
| urc.png | urc-automation.com site header; only a PNG is published |
| sonos.svg, ubiquiti.svg | Simple Icons (CC0) |
| bowers-wilkins.svg | Wikimedia Commons |
| kef.svg | kef.com site header (`img-KEF-logo_black.svg`) |

Used as a dealer/installer showing the brands it installs. Add a brand by
dropping the file here and adding a row to `FX_BRANDS` in js/app.js.
